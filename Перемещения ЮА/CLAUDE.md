# Правила проекта «Фемелі Маркет · Вывоз вне матрицы»

## Технологии
- GUI делаем на PySide6. Tkinter больше не используем (кроме старого кода до завершения переноса).
- Бизнес-логика (чтение выгрузок, свежесть, формирование списков, Excel, файлы для ТСД, журнал)
  живёт в отдельных модулях без импортов Qt. GUI только вызывает эти функции.
- Длительные операции (чтение Excel, формирование списков) выполняются в QThread,
  чтобы окно не зависало. Таблицы делай на QTableView с моделью.

## Дизайн
- Любую работу с интерфейсом начинай с чтения скилла pyqt6-ui-designer
  (.claude/skills/pyqt6-ui-designer/SKILL.md и все файлы в references/).
  Пиши код по его токенам, QSS-паттернам и библиотеке компонентов.
- Скилл написан для PyQt6, пересчитывай его под PySide6
  (Signal вместо pyqtSignal, Slot вместо pyqtSlot, импорты из PySide6).
- Когда экран готов, проведи UX-аудит по скиллу qt-ui-design
  (уровни Critical / Warning / Opportunity) и исправь Critical и Warning.
- Фирменные цвета: красный #E31E24, тёмная боковая панель. Язык интерфейса русский.
- Длинные пояснения не выводи серым текстом на экране, убирай их во всплывающие подсказки (tooltip).
- Должны быть светлая и тёмная темы.

## Порядок работы
- Переделывай по одному экрану, а не всё сразу.
- После каждого этапа запускай приложение и проверяй, что оно стартует без ошибок.
- Перед крупными изменениями делай git-коммит.
- Не трогай и не коммить папку .claude/worktrees и файл desktop.ini.

## Облако
- Если работаешь в облаке (Linux), проверяй окна в режиме QT_QPA_PLATFORM=offscreen:
  сохраняй скриншот окна через widget.grab() в PNG и оценивай его по скиллу qt-ui-design.
- Exe в облаке не собирай: сборка через PyInstaller делается на Windows локально.
