СИГАРЕТЫ — sigarety_tsd.exe
======================================================================

Отдельный инструмент. Расчёта потребности здесь нет: количество уже
готовое, программа только раскладывает его по магазинам и пишет файлы
для терминала сбора данных.


КАК ЗАПУСКАТЬ
----------------------------------------------------------------------
1. Двойной клик по sigarety_tsd.exe.
2. В первом окне выбрать файл раскладки (обычно «сигареты по маг.xlsx»).
3. Во втором окне выбрать папку, куда писать результат (обычно ЗАКАЗЫ).

Абсолютных путей внутри нет — программа спрашивает всё через окна
выбора, поэтому работает с любого компьютера и из любой папки.


КАК ПЕРЕСОБРАТЬ ПОСЛЕ ПРАВКИ
----------------------------------------------------------------------
1. Поправить sigarety_tsd.py.
2. Запустить build_sigarety.bat.
3. Новый sigarety_tsd.exe появится в этой же папке.

Временные файлы сборки складываются в _build — её можно удалять в любой
момент.


ЧЕГО ЗДЕСЬ НЕТ
----------------------------------------------------------------------
Ничего общего с расчётом перемещений (папка «РАСЧЕТ ЗАКАЗА»): другой
скрипт, другая сборка, другие данные. BigQuery не используется, ключ
сервис-аккаунта не нужен.
