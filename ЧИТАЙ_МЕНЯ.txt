ПЕРЕМЕЩЕНИЯ — что где лежит
======================================================================

Три независимые папки. Ничего между ними не пересекается: у каждой свой
скрипт, своя сборка exe и свои рабочие подпапки.


1. РАСЧЕТ ЗАКАЗА\        — перемещения РЦ → магазины (весь товар, кроме
                            сигарет и алкоголя)
2. СИГАРЕТЫ\             — раскладка сигарет по магазинам (без расчёта,
                            по готовому количеству)
3. ДОКУМЕНТЫ\            — спецификация и аналитические выгрузки


----------------------------------------------------------------------
1. РАСЧЕТ ЗАКАЗА
----------------------------------------------------------------------
    raschet_zakaza.exe          запускать двойным кликом
    raschet_zakaza.py           исходник (правится здесь)
    raschet_zakaza.spec         описание сборки
    build_raschet.bat           пересборка exe после правки .py
    ЧИТАЙ_МЕНЯ_расчет_заказа.txt подробная инструкция

    ВХОД\        сюда кладётся «Оборотная ведомость» из Торгсофта
    ЗАКАЗЫ\      сюда пишется результат (папка на каждую дату)
    ЛОГИ\        отчёты валидации, в том числе по сбоям
    АРХИВ\       прошлые версии скрипта
    Справочник\  кэш справочника упаковок (офлайн-запас)
    credentials\ ключ сервис-аккаунта BigQuery
    _build\      временные файлы сборки, можно удалять

Алкоголь и сигареты этот расчёт не трогает: алкоголь перемещается
программно в Торгсофте, сигареты — отдельным инструментом (папка 2).


----------------------------------------------------------------------
2. СИГАРЕТЫ
----------------------------------------------------------------------
    sigarety_tsd.exe            запускать двойным кликом
    sigarety_tsd.py             исходник
    sigarety_tsd.spec           описание сборки
    sigarety.ico                иконка
    build_sigarety.bat          пересборка exe после правки .py
    сигареты по маг.xlsx        рабочий файл раскладки
    ЗАКАЗЫ\                     результат
    _build\                     временные файлы сборки

Файл-источник и папку результата программа спрашивает через обычные
окна выбора файла. Никаких путей внутри не прописано.


----------------------------------------------------------------------
3. ДОКУМЕНТЫ
----------------------------------------------------------------------
    Спецификация_логистических_атрибутов_v1.1.html   действующая версия
    Спецификация_логистических_атрибутов_v1.0.html   предыдущая
    Оборачиваемость_и_возвраты_2026-08.xlsx
    Кандидаты_на_блок_перемещения.xlsx
    Блоки_безопасные_к_применению.xlsx
    Справочник_1.xlsx

HTML открывается двойным кликом в браузере.


----------------------------------------------------------------------
ПРАВИЛО
----------------------------------------------------------------------
Оба exe работают относительно своей папки. Чтобы отдать инструмент на
другой ноутбук — копируется папка целиком, ничего дописывать не нужно.
Не перекладывай exe из его папки: он ищет ВХОД, ЗАКАЗЫ и Справочник
рядом с собой.
